DenizenAdditions Tags


Tags are always written with a '<' before them, and a '>' after them, and are a way of reading information from the game.
These are only the ones DenizenAdditions adds. For everything in Denizen itself, see the Denizen Meta Documentation.

Name<ItemTag.consumable>
ReturnsMapTag
MechanismItemTag.consumable
Description(Property) Returns how an item is consumed when held down. Language:Item Components.
Map keys are "consume_seconds" (decimal), "animation" (one of: none, eat, drink, block, bow, trident, crossbow, spyglass, toot_horn, brush, bundle, spear),
"sound" (namespaced key), "has_consume_particles" (boolean), and "effects" (a ListTag of MapTags).

Each entry of "effects" has a "type" key choosing what it does, matching the vanilla consume effect names:
"apply_effects" - keys "effects" (a ListTag of potion effect maps, same format as Tag:EntityTag.effects_data) and optionally "probability" (decimal 0.0 to 1.0).
"remove_effects" - key "effects" (a ListTag of potion effect type names, or a single '#'-prefixed effect tag key).
"clear_all_effects" - no further keys.
"play_sound" - key "sound" (namespaced key).
"teleport_randomly" - key "diameter" (decimal).
GroupProperties
RequiresDenizenAdditions
Sourceorg/darwin/denizenAdditions/datacomponents/ConsumableAdapter.java#L1

Name<util.runlater[<id>]>
ReturnsMapTag
DescriptionReturns the run scheduled in Command:runlater under the given ID, as a map with keys:
"id": the ID it was scheduled with, if any.
"script": the ScriptTag that will run - missing if that script no longer exists.
"path": the script path, if one was given.
"time": a TimeTag of when it is due.
"player" / "npc": the linked player and NPC, if any.
"definitions": a MapTag of the named definitions, as given to 'def.<name>:' or 'defmap:'.
"definition_list": a ListTag of the positional definitions given to 'def:', as given - they are only matched
up with the task script's 'definitions' key once it actually runs.
Returns null if no run is scheduled under that ID.
RequiresDenizenAdditions
Sourceorg/darwin/denizenAdditions/tags/RunLaterTags.java#L23

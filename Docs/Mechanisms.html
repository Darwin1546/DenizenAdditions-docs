Nameconsumable
ObjectItemTag
InputMapTag
Related Tags<ItemTag.consumable> (Property) Returns how an item is consumed when held down. Language:Item Components. (...)
Description(Property) Sets how an item is consumed when held down. Language:Item Components.
Map keys are "consume_seconds" (decimal), "animation" (one of: none, eat, drink, block, bow, trident, crossbow, spyglass, toot_horn, brush, bundle, spear),
"sound" (namespaced key), "has_consume_particles" (boolean), and "effects" (a ListTag of MapTags).

Each entry of "effects" has a "type" key choosing what it does, matching the vanilla consume effect names:
"apply_effects" - keys "effects" (a ListTag of potion effect maps, same format as Tag:EntityTag.effects_data) and optionally "probability" (decimal 0.0 to 1.0).
"remove_effects" - key "effects" (a ListTag of potion effect type names, or a single '#'-prefixed effect tag key).
"clear_all_effects" - no further keys.
"play_sound" - key "sound" (namespaced key).
"teleport_randomly" - key "diameter" (decimal).
Provide no input to reset the item to its default value.
GroupProperties
RequiresDenizenAdditions
Sourceorg/darwin/denizenAdditions/datacomponents/ConsumableAdapter.java#L1
Namecustom_model_data_map
ObjectItemTag
InputMapTag
Related Tags<ItemTag.custom_model_data_map> (Property) Returns the item's full custom model data component, unlike Property:ItemTag.custom_model_data, which only handles a single number. Language:Item Components. (...)
Description(Property) Sets the item's full custom model data component, unlike Property:ItemTag.custom_model_data, which only handles a single number. Language:Item Components.
Map keys are "floats" (ListTag of decimal numbers), "flags" (ListTag of booleans), "strings" (ListTag of text) and "colors" (ListTag of ColorTags).
Missing keys are treated as empty lists.
Item model definitions read these by index: "range_dispatch" for floats, "condition" for flags, "select" for strings, and "tints" for colors.
Provide no input to reset the item to its default value.

Namehide_persistent_fakes
ObjectPlayerTag
InputElementTag
DescriptionHides persistentfake entities (see Command:persistentfake) whose id matches the given Language:Advanced Object Matching matcher from this player.
Already-visible matching fakes are despawned for this player immediately, and any new ones that would otherwise be sent to them later (e.g. on chunk load) are skipped too.
The matcher stays active in memory only (does not survive a relog/restart) until reversed with Mechanism:PlayerTag.show_persistent_fakes, using the exact same matcher text.
RequiresDenizenAdditions

Namerun_runlater_now
Objectsystem
InputElementTag
DescriptionRuns a task scheduled in Command:runlater immediately, by its specified unique ID, and drops it from the schedule
so it won't run again at its original time.
If the ID isn't in use, will silently do nothing.
Use Tag:util.runlater_ids to check whether there is a scheduled task with the given ID.
The task runs on the spot, synchronously, exactly as it would have when its timer came up.
See also Mechanism:system.cancel_runlater to drop it without running it.
RequiresDenizenAdditions
